# AI Index

Этот файл — точка входа для ChatGPT в репозиторий. Если ссылка на него передана в новой сессии, сначала прочитать этот индекс, а затем открывать нужные файлы по указанным путям.

## Репозиторий

Полный путь к репозиторию: `https://github.com/maxhuntorlean-debug/notion`

## Быстрые команды

Если пользователь пишет короткую команду вида `КН 1`, `КН 2`, `КН 3` и т.д., воспринимать это как команду открыть соответствующий раздел ниже без дополнительных уточнений.

- `КН 1` — открыть файл с фильмами и сериалами: `preferences/movies.md`.
- `КН 2` — открыть файл по английскому: `english-city-directions-phrases.md`.

Если позже появятся новые тематические файлы, добавлять им следующий номер `КН` и фиксировать здесь соответствие номера и файла.

После команды `КН N`:
1. открыть указанный файл;
2. использовать его содержимое как контекст для текущего запроса;
3. если пользователь просит что-то добавить, изменить или сохранить — обновить соответствующий файл в этом репозитории;
4. если полезный новый файл создаётся для будущих разговоров — добавить его в этот индекс и назначить ему следующий свободный номер `КН`.

## Файлы

### КН 1 — `preferences/movies.md`
Полный путь: `https://github.com/maxhuntorlean-debug/notion/blob/main/preferences/movies.md`

Список фильмов и сериалов, которые нравятся пользователю. Использовать для:
- рекомендаций фильмов и сериалов;
- выбора фильма на вечер;
- понимания предпочтений в кино;
- добавления новых понравившихся фильмов и сериалов.

### КН 2 — `english-city-directions-phrases.md`
Полный путь: `https://github.com/maxhuntorlean-debug/notion/blob/main/english-city-directions-phrases.md`

Конспект английских слов и фраз, которые изучались и отрабатывались в разговоре. Сейчас содержит лексику по ориентации в городе: направления, перекрёстки, светофоры, парк, лестницы и другие полезные выражения.

Использовать для:
- повторения английского;
- продолжения занятий с места, где остановились;
- тренировок и мини-диалогов;
- добавления новых изученных фраз.

## Правило обновления индекса

Когда в репозитории появляется новый файл с полезной для будущих разговоров информацией:
- добавить сюда его путь, полный GitHub-путь и короткое описание назначения;
- назначить ему следующий свободный номер `КН`;
- сохранить правило так, чтобы в новой сессии по команде `КН N` ChatGPT сразу понимал, какой файл нужно открыть.
