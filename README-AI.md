# AI Index

Этот файл — точка входа для ChatGPT в репозиторий. Если ссылка на него передана в новой сессии, сначала прочитать этот индекс, а затем открывать нужные файлы по указанным путям.

## Файлы

### `preferences/movies.md`
Список фильмов и сериалов, которые нравятся пользователю. Использовать для:
- рекомендаций фильмов и сериалов;
- выбора фильма на вечер;
- понимания предпочтений в кино;
- добавления новых понравившихся фильмов и сериалов.

### `english-city-directions-phrases.md`
Конспект английских слов и фраз, которые изучались и отрабатывались в разговоре. Сейчас содержит лексику по ориентации в городе: направления, перекрёстки, светофоры, парк, лестницы и другие полезные выражения.

Использовать для:
- повторения английского;
- продолжения занятий с места, где остановились;
- тренировок и мини-диалогов;
- добавления новых изученных фраз.

## Правило обновления индекса

Когда в репозитории появляется новый файл с полезной для будущих разговоров информацией, добавлять сюда его путь и короткое описание назначения.
